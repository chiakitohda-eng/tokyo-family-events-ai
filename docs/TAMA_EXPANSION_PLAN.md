# 多摩地域への対象拡大 計画書（2026-11-21 利用者指定・計画のみ）

利用者の指定：検索対象を23区だけでなく、立川などの多摩の主要市まで広げる。画面は「区」の絞り込みに「市」を追加し、23区と多摩を切り替えられるようにする。

この変更はスキーマ・検証・UI・収集ルールの改修にあたる。AGENTS.md のとおり、main（ステージング）で実装し、実表示を利用者に見せて明示承認を得てから production に反映する。データ（多摩のイベント）は、アプリ側の対応が本番に出るまで data-production に入れない（入れると検証が通らない、または画面に出ない）。

## 2. 設計（データのフィールド名は変えない）
- イベントの `ward` に市名（例「立川市」）を入れる。フィールド名を変えると既存データ・履歴・検証すべてに波及するため、`ward` は「区・市」の意味に広げる。
- 区・市の一覧を `WARDS`（23区）と `TAMA_CITIES`（多摩20市）に分け、`AREAS = WARDS + TAMA_CITIES` を検証とUIで使う。
- 週ファイルの `coverage.wards` は23区のまま必須とし、多摩は任意の `coverage.municipalities`（市ごとの確認状況）を新設する。23区の厳格検証（全区checked）は多摩の有無に影響されない。
- 画面：絞り込みの上に「23区 / 多摩」の切り替えを置き、既定は23区。選択中のグループの区・市だけをチップ表示する。件数表示・並び順・重複まとめ（同名・同日・同区市）は市にも同じルールを適用する。
