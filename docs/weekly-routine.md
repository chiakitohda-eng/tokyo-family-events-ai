# 毎週のイベント収集ルーティン(ちあ用)

投稿は毎週水曜夕方。**月曜〜火曜**に下の1〜3を実行する。

## 1. 取りこぼしスキャンを動かす(GitHub・スマホ/PCのブラウザ)
1. https://github.com/chiakitohda-eng/tokyo-family-events-ai/actions を開く
2. 左の一覧から **Weekend gap scan (read only)** を選ぶ
3. 右上の **Run workflow** を押す → 緑の **Run workflow**(日付は空欄でOK。次の土曜日が対象)
4. 約10〜20分で緑のチェックになる。終わったら Claude に「スキャン終わった」と伝える

## 2. Claude に貼るプロンプト(コピペ)
```
tokyo-family-events-ai の Weekend gap scan が終わりました。
対象は今週末(次の土日)です。
1. 最新の weekend-gap-scan のArtifactを読み、hits を確認してください。
2. 公式ページで日時・会場・費用・申込要否・対象年齢を1件ずつ確認し、根拠URL付きの表にしてください(未確認のものは「未確認」と明記)。
3. 申込締切済み・満席・大人向けのものは外してください。
4. 競合リスト(あれば添付)と付け合わせ、足りないものと、取れなかった原因を教えてください。
5. 確認できたものだけ、イベントテンプレに流し込む準備をしてください。
```

## 3. Canva に流し込む
確認済みイベント名を Claude に伝える → Claude が「イベントテンプレ」から新規デザインを作る。

## 補足
- スキャンは読み取り専用。公開データ・本番は変えない。
- 見つからなかったソースは `policy/weekend_gap_sources.json` に追加する(Claude に「○○区のイベント一覧を追加して」と頼む)。
- 競合に載っていたのに拾えなかったイベントは `policy/weekend_gap_benchmark.tsv` に1行足すと、次回から自動で拾えたか確認される。
